# personal-expense
--> Project Title: Personal Expense Manager (Smart Expense Analyzer)

Problem Statement: Daily expense tracking ke challenges, budgeting issues aur unorganized manual logs.

Objective: Zero-cost, privacy-friendly, interactive expense tracker with strict validations.
 
Features:
Modern Financial Dashboard (4 KPI metric cards + Recent transactions)

Interactive Plotly Visualizations (Donut chart with % share & Bar chart with ₹ values)

Add Expense with calendar date picker & category dropdown

View Expenses with Indian Rupee formatting & CSV export

Keyword Search across descriptions and categories

Filter & Sort (Ascending / Descending by amount)

Update Expense with pre-filled inputs

Delete Expense with safety confirmation
Summary & Analytics with complete category breakdown
Technologies Used: Python 3.9+, Streamlit, Plotly, Pandas, Matplotlib, JSON, Unittest.
Installation / Setup Instructions: Step-by-step virtual environment & package installation.
How to Run the Project:
Streamlit Web UI: python -m streamlit run app.py
CLI Application: python main.py
Project Structure: Complete directory tree description.
Testing Details: Unit test command and 10 test case breakdown.
Limitations: Single-user scope, JSON scale, Single currency standard.
Future Improvements: Category budget threshold alerts, Income tracking, Receipt OCR scanner, PDF exports.
